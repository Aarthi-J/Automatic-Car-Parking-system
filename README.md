# Automatic Car Parking System

An IoT-based Automatic Car Parking System designed to simplify vehicle entry, parking slot management, booking, and payment.

## Project Description

The system uses RFID technology to identify and register vehicles at the parking entrance. After registration, IR sensors detect the availability of parking slots. Servo motors are used to control the entry and exit mechanism.

LEDs and a buzzer provide visual and audio indications during vehicle entry and parking operations.

We also developed a web-based platform where users can:
- View available parking slots
- Book a parking slot online
- Make online payments
- Monitor parking slot availability

## Key Features

- RFID-based vehicle registration
- Automatic parking slot detection
- Automatic entry and exit control
- Real-time parking slot availability
- Online parking slot booking
- Online payment facility
- Buzzer and LED indications
- Web-based parking management

## Working

1. The vehicle reaches the parking entrance.
2. The RFID sensor reads the vehicle's RFID card/tag and registers the vehicle.
3. IR sensors detect whether parking slots are occupied or available.
4. The system controls the entry/exit mechanism using servo motors.
5. LEDs and the buzzer provide status indications.
6. Users can check available slots through the website.
7. Users can book a slot and make the payment online.
